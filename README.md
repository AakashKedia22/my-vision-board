## Features

- **Pillars layout (default):** title + gold rule + 「2026 · 丙午年」year mark + enso watermark + one card per workstream (kanji seal, name, own-words text, per-pillar next step). Editable, add/remove up to 9 pillars.
- **Board (1000×1500) + Wallpaper (1080×1920)** renders + **↓ Both** one-click download.
- **Auto-save:** every edit persists to `localStorage` on this device. `↺ Reset to defaults` restores.
- **7 Japan-inspired themes:** Japan (vermillion + gold), Sumi ink, Sakura, Matcha, Kyoto Indigo, Torii dusk, Cream.
- **4 layouts:** Pillars 八, Photo grid, Hero photo, Words only — enso + kanji strip appear on non-photo layouts.
- **Static PNGs included:** `my-vision-board.png` / `my-vision-wallpaper.png` (pre-rendered defaults; regenerate live from the page after edits).

## Quarterly reset

At the start of each quarter: re-open page → edit pillars/steps → ↓ Both → set wallpaper as lock screen.

## Privacy

`noindex`, no network calls (telemetry removed from upstream), all rendering in `<canvas>`, state in `localStorage` only.
